# KRX 검증 종가 구간과 급락 조기경보 초기 백테스트

## 입력 구간 분리

[`KRX 공식 전수 대조`](../krx-full-validation-20261021/README.md)에서 날짜·종가가 확인된 **2010-01-04~2026-10-20 KOSPI·KOSDAQ 각 4,133거래일**만 연구 입력으로 분리했다. `run.py`는 로컬 KRX 가격과 검증 결과를 읽고, 날짜 중복·범위·네이버와의 날짜별 종가 일치를 다시 확인한다. 분리한 `validated_closes.local.csv`는 원본 가격 재배포 권한이 확인되지 않아 서버에만 보관한다. [`metrics.json`](metrics.json)에 원본·검증 결과·분리 파일의 SHA256을 기록했다. 가격값의 정합성 검증과 이용 허가 판단은 별개다.

1996~2009년은 백테스트 입력에서 제외했다. 전체 기간의 공식 거래일과 종가가 검증되면 같은 정의로 장기 성능을 **재평가할 예정**이며, 이번 결과를 30년 성능으로 표시하지 않는다.

## 고정 기준선 모델

별도 급락 조기경보 모델 구현이 확인되지 않아 종가만 사용하는 초기 기준선을 실행했다. 각 거래일 **종가 확인 후** 최근 20거래일(당일 포함) 최고 종가 대비 당일 종가가 5% 이상 낮으면 경보를 낸다. 목표는 **다음 20거래일** 중 현재 종가 대비 10% 이상 하락한 날의 존재다. 임계값을 데이터에 맞춰 학습·조정하지 않았다. 2010~2017년은 개발 관찰 구간, 2018년 이후는 사전 지정 평가 구간으로 분리했다. 미래 20거래일이 완성되지 않은 2026-09-17 이후는 평가에서 제외했다.

| 지수·2018~2026 평가 | 평가일 | 경보일 / 연속 경보 구간 | 목표 발생일 | 정밀도 | 재현율 | 전체 목표 발생률 대비 정밀도 배수 |
|---|---:|---:|---:|---:|---:|---:|
| KOSPI | 2,137 | 407 / 64 | 162 | 13.02% | 32.72% | 1.72배 |
| KOSDAQ | 2,137 | 645 / 93 | 326 | 25.27% | 50.00% | 1.66배 |

KOSPI는 경보 407일 중 53일이 목표와 맞았고 354일은 맞지 않았다. KOSDAQ은 645일 중 163일이 맞고 482일은 맞지 않았다. 목표 발생일의 기본 비율은 각각 7.58%, 15.26%다. 기준선의 잦은 오경보와 미탐지가 확인됐으며, 실사용 경보 성능을 입증하지 못했다.

각 날짜의 미래 20거래일 목표가 서로 겹치고 연속 경보도 여러 날을 세므로, 일 단위 정밀도·재현율은 독립적인 위기 사건 단위 성능이 아니다. 거래비용·실행시점·지수 구성 변경·시장 외 변수는 평가하지 않았다. 실제 예측 신호는 종가가 확정된 뒤에만 알 수 있으며, 같은 날 장중 의사결정에 사용할 수 없다. 연구 전용 결과이며 MMP 운영 코드·MI 규칙·MyDream2000은 변경하지 않았다.

재현 코드는 [`run.py`](run.py)다. 기존 로컬 입력과 출력이 있으면 덮어쓰지 않는다.
