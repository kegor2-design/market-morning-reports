# 1996~2009 KRX 공식 역사 자료와 이용 허가 확인

## 확인된 사실

- 기존 KRX 웹 계정의 `MDCSTAT00301` 조회에서 1996년 KOSPI·KOSDAQ, 2008년 양 지수 및 기존 1997~2001년 불일치일의 공식 종가가 반환됐다. 표본 **22개 지수·날짜**는 확보했으나, **1996~2009년 전체 거래일·종가 자료는 확보하지 않았다.** [표본 조회 기록](../krx-full-validation-20261021/README.md)을 참고한다.
- [KRX Open API 서비스 목록](https://openapi.krx.co.kr/contents/OPP/INFO/service/OPPINFO004.cmd)은 KOSPI·KOSDAQ 일별 시세를 **2010-01-04 이후**부터 제공한다고 명시한다. 따라서 Open API만으로 1996~2009년을 채울 수 없다.
- [KRX Data Marketplace 홈페이지 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd)은 사전 허락 없는 정보 복제·배포와 자동화 수단을 이용한 무단 수집을 금지한다. 웹 로그인 성공은 역사 자료의 일괄 수집·보관·백테스트·공개 허가를 증명하지 않는다. **현재 이용 허가는 확인되지 않았다.**
- KRX는 [데이터 상품 소개](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO008.cmd)와 데이터 구입 경로를 안내하지만, 공개 안내만으로 필요한 1996~2009년 개별지수 일간 원본의 상품명·제공 범위·가격·사용권을 확정할 수 없었다.

## KRX에 확인할 내용

다음 문의 초안은 **발송하지 않았다**. KRX의 답변과 명시적인 이용 조건이 확보되기 전에는 1996~2009년 자동 전수 수집을 진행하지 않는다.

> 연구용으로 KOSPI·KOSDAQ 대표지수의 1996-01-01~2009-12-31 일별 공식 종가와 거래일 자료가 필요합니다. 해당 기간의 완전한 역사 자료를 제공하는 공식 상품·추출 방법, KOSDAQ 기준지수 변경에 따른 소급 계열 정의, 정정 이력 및 거래일 달력 제공 여부를 알려 주십시오. 내부 연구 보관, 급락 조기경보 백테스트, 집계 성능 공개, 원시 가격 비공개 각각의 허용 범위와 필요한 승인·계약·비용을 확인하고 싶습니다. 웹 화면의 자동 조회 허용 여부와 요청량 제한도 함께 안내해 주십시오.

KRX의 공식 답변이 오면 출처·제공기간·계열 정의·이용 허가·재배포 제한을 기록하고, 그때 1996~2009년 전수 검증과 30년 백테스트를 진행할 수 있다. 현재 상태는 **자료 일부 확인 / 전체 확보 전 / 이용 허가 미확인**이다.
