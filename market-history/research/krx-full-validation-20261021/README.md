# KRX 공식 KOSPI·KOSDAQ 전수 대조 — 2026-10-21

## 범위와 수집

기존 MMP가 사용하는 PyKRX 웹 로그인 절차를 한 번 실행하고 같은 인증 세션에서 KRX Data Marketplace `MDCSTAT00301`을 49회 조회했다. 2010~2026년은 지수별 연 단위 34회, 1996~2009년은 초기·2008년 표본 4회와 기존 공급자 불일치일 11회다. 요청 간 최소 2.5초를 기다렸고, 실패 응답에 대한 자동 재시도는 하지 않았다. 로그인은 HTTP 200·`CD001`, 시세 조회는 **49/49회 HTTP 200**이었다. 요청별 범위·행 수·상태는 [`result.json`](result.json)에 있다.

기존 [`daily-index-validation-20261021`](../daily-index-validation-20261021/README.md)의 로컬 네이버·Yahoo 일간 CSV와 날짜·종가를 대조했다. 종가 허용 오차는 기존 검증과 동일한 **0.0101 지수 포인트**다. KRX 응답의 날짜 집합을 해당 지수의 공식 거래일로 사용했다. 기간은 **2010-01-01~2026-10-20**이며 실제 첫 공식 거래일은 2010-01-04다. 진행 중인 2026-10-21 장은 포함하지 않았다.

Yahoo에서 공식 거래일에 유효 가격이 없는 날짜는 양 지수 공통 **2017-09-22, 2017-12-20, 2022-01-03, 2022-05-09**, KOSPI 추가 **2011-10-04**다. 이 기간에 공급자에만 있고 KRX에는 없는 유효 가격 날짜는 0건이었다. Yahoo의 가격 공란 행은 대조·거래일 판정에서 제외했다.

## 1996~2009년 표본과 기존 13건 판정

같은 조회 방식으로 KOSPI **1996-01-03~05 3일**, KOSDAQ **1996-07-02~05 4일**, 2008-10-01~05 기간의 양 지수 **각 2거래일**을 확보했다. 이 11개 지수·날짜의 네이버 종가는 모두 KRX와 일치했다. Yahoo가 유효 가격을 제공한 2008년 4건도 일치했다. 따라서 웹 조회 방식이 2010년 이전에도 작동함을 확인했다. **1996~2009년 전체 거래일·종가 검증은 아직 하지 않았다.**

기존 공급자 간 종가 불일치 13건은 모두 해당 날짜의 KRX 공식 종가를 확보해 판정했다.

## 데이터 이용과 미검증 항목

KRX 원본 종가와 날짜별 상세 대조는 서버의 `official.local.csv`, `comparison.local.csv`에만 보관한다. GitHub에는 요청 메타데이터와 집계·판정만 게시했다. [KRX Data Marketplace 홈페이지 이용약관](https://data.krx.co.kr/contents/MDC/INFO/informationController/MDCINFO003.cmd)은 사전 허락 없는 정보 배포와 자동화 수단을 이용한 무단 수집을 금지한다. 기존 웹 계정이 대량 자동 조회의 허가까지 의미하는지는 확인되지 않았다. 따라서 **추가 자동 조회나 원본 시세 공개 전에 KRX의 이용 허가 범위를 확인해야 한다.** 이번 조회는 웹 세션을 사용했고 Open API 키·이용승인과는 별개다. 원본 시세의 외부 재배포 허용 범위가 확인되지 않아 상세 가격표를 게시하지 않았다.

2010~2026년의 공식 종가·거래일 대조는 완료했으나, **1996~2009년의 표본 외 날짜**, 공급자 OHLCV와 거래대금, 지수 산식·소급조정 이력은 미검증이다. 특히 2001-11-01 KOSDAQ은 네이버 종가가 공식값과 다르므로 기존 30년 자료 전체를 무조건 확정 데이터로 사용할 수 없다. 기존 자료와 운영 코드·MI 규칙·MyDream2000 환경은 변경하지 않았다.

수집 스크립트 `collect_validate.py`도 서버 연구 폴더에만 보관한다. 기존 로컬 산출물이 있으면 덮어쓰지 않고 중단하도록 작성했다.
