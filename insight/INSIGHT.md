# 우리의 시장 인사이트

이 문서는 MarketMorningPublisher의 Codex 분석이 사용하는 현재 원칙이다. 특정 투자자나 투자사의 관점을 최종 결론으로 사용하지 않는다. 외부 관점은 출처가 있는 후보일 뿐이며, 아래 `MI-*` 원칙만 현재 판단 근거로 사용한다.

## 활성 원칙

- `MI-001 v1` 뉴스는 매매 신호가 아니라 시장 상태 변화의 증거다. 사실, 기대 대비 차이, 전달경로, 가격 확인 순서로 본다.
- `MI-002 v1` 현재 실적보다 미래 이익의 방향과 리비전 속도를 우선한다. 이익 증가, 증가율 둔화, 절대 감소를 구분한다.
- `MI-003 v1` 산업 사이클을 주문, 재고, ASP, 가동률, CAPEX, 공급, 수주잔고로 분해한다.
- `MI-004 v1` 경기침체·이익 붕괴·구조 훼손과 강제청산성 하락을 구분한다. 낙폭만으로 저가매수 결론을 내리지 않는다.
- `MI-005 v1` 지수 등락과 시장 내부 확산을 분리한다. breadth, 동일가중, 신고가·신저가, 섹터 상대강도를 확인한다.
- `MI-006 v1` 현물, 선물, 옵션, 베이시스, 프로그램, 환율, 신용·반대매매를 함께 본다.
- `MI-007 v1` 차트와 가격은 예측 공식이 아니라 심리·수급·추세 확인 계기판이다.
- `MI-008 v1` 다음 장, 1~4주, 1~6개월 결론을 분리한다.
- `MI-009 v1` 모든 결론에 반대 근거, 무효화 조건, 누락 데이터와 확신도를 포함한다. 데이터 부재는 `UNKNOWN`이다.

## 인과 순서

`정책·유동성·금리·환율 → 수요·미래 이익 → 주문·재고·가격·공급 → 포지셔닝·강제청산 → breadth·상대강도 → 가격 확인`

## 시장 상태

- `RISK_ON_TREND`: 이익, 시장 내부, 가격이 함께 개선
- `RISK_ON_SELECTIVE`: 지수는 우호적이나 산업·종목 확산 제한
- `CHOPPY`: 거시, 이익, 수급 신호 충돌
- `RISK_OFF_WEAK`: 이익 하향 또는 금융여건 악화
- `RISK_OFF_PANIC`: 강제청산과 시장 내부 붕괴 동시 발생
- `RECOVERY_EARLY`: 청산 진정 후 선도 산업·종목이 먼저 회복
- `UNKNOWN`: 필수 근거 부족

## 금지사항

- 기사 제목의 긍정·부정 감성을 시장 방향으로 대체하지 않는다.
- 알 수 없는 실적, 컨센서스, 수급, 가격을 추정하거나 만들어내지 않는다.
- 외부 인물·투자사 이름을 점수나 진실의 근거로 사용하지 않는다.
- 시장지수 경험칙을 개별 종목이나 레버리지 상품에 일반화하지 않는다.
- 하나의 불투명한 점수로 모든 판단을 합치지 않는다.
